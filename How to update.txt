BS19 v1.05 Hotfix — How to update

This is a fixes-only update for the public framework. It does not include the
new parkour, fighting, Survivor Link, voice/radio, weapon editor, themes or
building systems being worked on for v1.1. No database migrations are added.

1. Stop the server and back up its folder and database.
2. Download v1.05 into a separate folder. Do not run the fresh-install recipe
   against an existing server, and do not extract the download over your files.
3. Use the list below to review the changed files. If you never edited a listed
   file, take the v1.05 copy. If you edited it, compare your installed release,
   your current copy and v1.05, then merge the fix into your copy. Keep a backup.
4. Update related files together. In particular, take bs_core with the teleport
   callers and bs_pause; take both client and server zombie changes; and take
   both inventory capture files. Skipping one side can leave a fix incomplete.
5. Keep your server.cfg, credentials, F1 profiles, custom resources and database.
   Compare changed config files instead of replacing your settings blindly.
6. Restart the full server. If a problem appears, stop it and restore the changed
   files from your backup. Restore the database separately only if necessary.

update-v1.05.json lists the same paths with before/after SHA-256 hashes. A hash
mismatch means your file differs; it is a reason to review, not to overwrite it.
Hashes use LF line endings (convert Windows CRLF to LF before comparing).
There is no automatic updater bundled with this hotfix.

Guide: https://bs19.org/docs/owners/how-to-update/
