# bs_gadgets

Deployable gadgets (drone, turret, medic beacon, decoy) and the riot shield. 2 slots, default keys 9 / 0. See docs/GADGETS.md.

Riot shield credit: based on **Shield Mod** by winject - https://www.gta5-mods.com/scripts/shield-mod
(Lua rewrite of the behaviour; uses vanilla game props, no files from the mod are included).
