# Установка BeyondSurvival

Гайд рассчитан на тех, кто ни разу не поднимал сервер FiveM. Идёшь сверху вниз и минут через 20 у тебя рабочий сервер.

Ставить можно двумя способами:

- **A - рецепт txAdmin** (проще всего, рекомендуем)
- **B - ручная установка** (если хочешь сделать все шаги сам)

---

## Что нужно

- ПК с Windows или VPS на Windows/Linux. Минимум 8 ГБ RAM и 10 ГБ свободного места на диске.
- **Аккаунт Cfx.re** и **лицензионный ключ сервера**. Ключ берётся тут: https://portal.cfx.re -> Server Keys -> Generate.
- **MariaDB** (бесплатный сервер баз данных). Скачай с https://mariadb.org/download и поставь с настройками по умолчанию. Во время установки задашь **пароль root** - запиши его, он понадобится.
- GTA V и FiveM на ПК, с которого играешь, чтобы заходить и тестить.

---

## A - Установка через рецепт txAdmin

### 1. Скачай артефакты сервера

1. Зайди на https://runtime.fivem.net/artifacts/fivem/build_server_windows/master/
2. Скачай последнюю **recommended** сборку (`server.7z`).
3. Создай папку, например `C:\FXServer\server`, и распакуй туда 7z. Для этого нужен 7-Zip (https://7-zip.org).

### 2. Запусти txAdmin

1. Открой папку `server` и дважды кликни **FXServer.exe**.
2. Откроется окно консоли, а в браузере откроется txAdmin (если нет, зайди на http://localhost:40120).
3. Введи PIN из консоли, войди через аккаунт Cfx.re и создай пароль txAdmin.

### 3. Разверни BeyondSurvival

1. В мастере настройки дай серверу имя и выбери **Remote URL Template**.
2. Вставь этот URL:
   ```
   https://raw.githubusercontent.com/Arcainex/bs19/main/recipe.yaml
   ```
3. Выбери, куда складывать данные сервера (путь по умолчанию подойдёт), и жми дальше.
4. Когда txAdmin спросит **license key**, вставь ключ с portal.cfx.re.
5. На шаге с базой данных укажи:
   - Host: `localhost`
   - Port: `3306`
   - Username: `root`
   - Password: пароль root от MariaDB, который ты задавал раньше
   - Database name: оставь как есть
6. Нажми **Run Recipe** и подожди. Качается фреймворк, так что это займёт несколько минут.
7. Когда закончится, нажми **Save & Run Server**.

Всё. txAdmin уже прописал в конфиг твой license key, базу данных и твой аккаунт как админа. Таблицы в базе создадутся сами при первом запуске сервера.

Переходи к разделу **После первого запуска** ниже.

**Необязательно: карта.** Карта в комплект не входит. Скачай её с https://github.com/Arcainex/The-Apocalypse-Project, положи папку `[the_apocalypse_project]` в `resources/[map]`, потом открой `server.cfg` и убери `##` перед строкой `ensure [the_apocalypse_project]`.

## B - Ручная установка

### 1. Артефакты и txAdmin

Сделай шаги 1 и 2 из части A.

### 2. Достань файлы

1. Скачай BS19 с https://github.com/Arcainex/bs19 (зелёная кнопка **Code** > **Download ZIP**).
2. Создай папку для данных сервера, например `C:\FXServer\beyondsurvival`, и распакуй туда zip. Внутри должны быть `resources` и `server.cfg`.
3. Скачай oxmysql с https://github.com/overextended/oxmysql/releases (файл `oxmysql.zip`) и распакуй в папку `resources`, чтобы получилось `resources\oxmysql`.

### 3. Создай базу данных

1. Открой **HeidiSQL** (идёт вместе с MariaDB) и подключись с пользователем `root` и своим паролем root.
2. Правый клик по подключению -> Create new -> Database. Назови её `beyondsurvival`, collation `utf8mb4_unicode_ci`.
3. Оставь пустой. BeyondSurvival создаёт все таблицы при первом запуске.

### 4. Поправь конфиг

1. Открой `server.cfg` в Блокноте.
2. Впиши свой license key в строку `sv_licenseKey`, туда, где стоит `CHANGEME`.
3. В строке `mysql_connection_string` замени `CHANGEME_USER` на `root`, а `CHANGEME_PASSWORD` на свой пароль root.
4. Хочешь свое название сервера? Поменяй строки `sv_hostname` и `sv_projectName`.
5. Добавь себя в админы (смотри **Как выдать админку** ниже).
6. После этого никому не показывай `server.cfg`, в нем твой ключ и пароль.

### 5. Подключи txAdmin

1. В мастере txAdmin выбери **Existing Server Data** и укажи свою папку (`C:\FXServer\beyondsurvival`).
2. Когда спросит файл конфига, выбери `server.cfg` и запускай сервер.
3. В txAdmin зайди в **Settings -> FXServer** и проверь, что **OneSync** стоит на **On**.

## После первого запуска

- Следи за консолью. Первый запуск дольше, потому что создаются таблицы в базе и сервер кэширует свои файлы.
- Открой FiveM, нажми F8 и введи `connect localhost` (или IP своего VPS).
- Создай персонажа, и ты в игре.

## Как выдать админку

У админов есть меню настроек на F1, админ-меню, /atlas и дебаг-команды.

1. Пусть игрок один раз зайдёт на сервер.
2. В txAdmin открой **Players**, кликни по игроку и скопируй строку, которая начинается с `license:`.
3. Открой `server.cfg`, пролистай в самый низ и добавь:
   ```
   add_principal identifier.license:PASTE_IT_HERE group.superadmin
   ```
   Для обычного стаффа ставь `group.admin` вместо `group.superadmin`.
4. Перезапусти сервер.

Если ставил через рецепт, твой аккаунт там уже есть как `group.admin`. Замени это слово на `group.superadmin`, если нужны полные права владельца.

## Как менять настройки

- Почти всё можно менять прямо в игре через **F1** (только для админов). В режиме Simple самое ходовое (количество зомби, дистанция спавна, голод, лут...). В режиме Advanced видно вообще всё.
- У каждого ресурса также есть папка `config` с прокомментированными настройками, если тебе проще править файлы.

## Проблемы?

| Что видишь | Что делать |
|---|---|
| `Could not connect to database` | Неверный логин/пароль в `server.cfg`, или MariaDB не запущена. |
| `License key invalid` | Скопируй ключ с portal.cfx.re заново, без пробелов. |
| Сервера нет в списке серверов | Открой порты 30120 TCP и UDP на роутере/в фаерволе. |
| Игроки зависают на загрузке | Проверь, что OneSync включён (On) и билд игры 3095. |
| Ползающие зомби скользят | `nutria_crawl_anims` должен стартовать раньше `bs_zombies` в `server.cfg`. |

Всё равно не выходит? Заходи в наш Discord (ссылка на https://bs19.org) и кидай красные строки из консоли.
